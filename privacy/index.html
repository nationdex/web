The following document explains what data is collected by Nationdex, how it is processed, stored, and the rights you possess regarding your personal information.

Glossary

  • Application / Discord application: refers to the Discord bot user, its associated owners and the servers it has joined.
  • Data: refers to data stored by an individual instance, including personal data.
  • Bot / instance: refers to the copy of the code running the Discord application, operating with its own database.
  • Collectible: refers to any virtual object that is meant to be collected, such as countryballs, regional nations, or other elements.
  • Application owners: refers to the owners of the Discord application, meaning those with access to authentication credentials and database contents. This is referred to as the "Nationdex core team".
  • Nationdex moderation team: refers to the owners of the Discord application and the users selected to support moderation duties.

Open source

The code powering Nationdex is open source under the Apache 2.0 License and is available publicly. You may inspect the code to verify how data is managed, in addition to reading this policy.

What data is collected

Nationdex collects the following data from Discord to enable core game mechanics:

  • User IDs: used to identify your unique account inside our player database.
  • Server (Guild) IDs: used to store settings necessary to the bot's custom server configuration and operation.
  • Channel IDs: used to determine in which specific channels collectibles should spawn.

In addition, the following gameplay-specific metadata is created and managed within Nationdex:

  • The list of collectibles owned by a user of the service.
  • A history of trades done on collectibles, including the records of players that previously owned the said collectible.
  • Various settings configured by an individual user or the server, such as player policies or spawn silent options.

The bot has access to message content but uses it solely for the purpose of anti-cheat and verification. Said content is analyzed instantaneously (under one second) and never stored permanently or cached. Message content cannot be accessed or read by administrators.

How the data is stored

All persistent user data is stored securely in structured relational databases hosted on private VPS (Virtual Private Server). Database access is strictly confined to local connections using secure object-relational mapping (ORM) libraries, preventing external database exposure.

Cookies

Nationdex uses cookies and browser local storage strictly for essential website functionality, user preferences, and performance optimizations. We do not use third-party tracking cookies or advertising cookies.

The following items may be stored on your device when using our web services:

  • nationdex_cookie_consent: stores your cookie banner consent preference (e.g. accepted or custom settings) so you are not prompted repeatedly.
  • ndex_theme: stores your light/dark mode UI theme preference.
  • ndex_lang: stores your selected language preference for the website interface.
  • ndex_servers, ndex_users, ndex_commands: caches live public statistics for performance optimization.
  • googtrans (Google Translate): essential cookies used to preserve selected language translations across pages.

You can clear or manage cookies and local storage items at any time through your browser settings or by interacting with our cookie settings panel.

Access to the data

The only people authorized to access underlying server databases are the application owners (the Nationdex core team). Modulators and standard staff members do not have direct access to database records. The data is secured using industry-standard measures and is never sold, traded, or made available to the public.

Your rights

You have the absolute right to request a copy of your personal data or demand the complete deletion of your records from our databases. You can exercise these rights at any time by contacting the application owners.

The recommended method of contact is by email at contact@nationdex.com or via our official support portal in our Discord server.
